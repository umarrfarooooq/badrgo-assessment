# Rules & Conventions

## Core Philosophy

- DRY — every piece of logic lives in exactly one place
- No inline comments — code must be self-documenting through naming
- Production-ready from day one — no shortcuts that require rewrites
- Every edge case is a first-class concern, not an afterthought

---

## Code Style

- No comments anywhere in source code — rename until the code explains itself
